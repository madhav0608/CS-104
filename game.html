Minesweeper Cricket

Rules for 1 player game

  • Select the grid size you want to play on beside.
  • On the grid, there will be 11 random fielders alloted randomly.
  • If you click on a square which is not fielder you will gain some score depending on the score alloted to that cell of the grid like 1, 2, 3, 4 or 6.
  • Game Winning Condition : You should select all the squares without fielders.
  • Game Losing Condition : If you select a square containing fielder.
